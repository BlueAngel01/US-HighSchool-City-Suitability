# 01 - City Selection

## Research Objective
Identify representative U.S. metropolitan areas across the nine Census Divisions.

## Methodology
- Population eligibility screening
- Five-indicator city representation model
- Stratified global p-Median optimization
- Marginal coverage contribution analysis
- Monte Carlo sensitivity analysis

## Data and Reproducibility
This directory contains city selection datasets, Python scripts, model specifications, and reproducible results.

All geographic definitions, data sources, and calculation rules should be documented.
